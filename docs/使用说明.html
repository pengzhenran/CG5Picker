CG5 数据挑选 —— 使用说明

处理 CG-5 相对重力仪导出的手簿（.txt）：按日期 / Survey / 条件挑出可用观测， 看图形确认，再按原始格式导出 Excel。与课题组其它小软件（SHKit / SHSynth）是同一套版式与作者。

1. 这是什么

CG-5 手簿里一天、一个 Survey 往往测了几十上百次读数，一个测点重复观测若干次。 这个工具把这些读数整理成一张可复核的表，按现场口径自动筛一遍，你再看图形确认、 手工加减，最后导出成 Excel。

它只做这一件事，不做段差、平差、网平差 —— 那些交给大软件。

2. 安装与启动

  1. 拿到 CG5Picker_Setup_v1.0.0.exe，双击，按向导下一步即可（默认按当前用户安装，不弹管理员授权）。
  2. 装完在开始菜单里会有 CG5 数据挑选；安装时勾选「创建桌面快捷方式」的话桌面上也有一个。
  3. 双击图标就能用。不需要装 Python、不需要联网，运行需要的东西都在安装包里。
  4. 卸载：开始菜单里的「卸载 CG5 数据挑选」，或 Windows「设置 → 应用」里卸载。
换电脑/换用户：直接在新机器上装一遍即可；界面习惯与条件组合存在安装目录的 config\ 下（见第 10 节）， 想带走就把那两个文件拷过去。

3. 界面总览

区域干什么
最上面一行打开手簿 / 重新载入 / 查看原数据 / 使用说明 / 关于；右边实时显示 「命中 N / 全部 M 条（日期…｜Survey…）」
① 范围左边选日期、右边选Survey。两条线是且的关系（求交集）： 缺哪一边都是 0 条
② 筛选条件条件栈（勾选即生效）+ 参数组合 + 判定式 + 日志
④ 结果表一行一条观测，勾选=保留、取消=剔除；可排序、可拖列序
⑤ 图形四种视图，与表格双向联动

4. 第一步：打开手簿、选范围

  1. 点「打开 CG-5 手簿…」，选一个 .txt。一个文件里通常有好几天、好几个 Survey， 会全部解析出来（日期、Survey、仪器 S/N、经纬度、操作者…）。
  2. 日期默认选最新一天；Survey 默认把那一天里的全勾上。
  3. 想反过来按 Survey 找日期：点「按 Survey」，左边变成 Survey、右边变成日期，两边仍然是且。
两条线都要选：把日期全部取消 = 0 条（不是"全部数据"）。这是有意的 —— 免得"明明清空了范围却还在按旧条件筛"。

5. 筛选条件

连接词：首要 / 或 / 且

连接角色判定
首要第一块：门槛勾上的都必须满足
或第二块：或组这一组里至少一条满足即可
且第二块：且组这一组里每条都要满足

判定 = 首要 ∧（或组）∧（且组），空组不参与。表下面那行「判定：…」就是当前条件栈的人话版。

「或」组的天花板 = 组里最松的那条。比如把「观测时长 ≥35 s」放进「或」组， 等于"只要时长够就算过"，严格的互差判据会被它顶掉，屏幕上立刻变成"几乎全都满足"。 常规门槛（时长 / REJ / 倾斜）请用首要或且；「或」留给"多种判据任选其一"（例如两条互差）。

条件表各列

列含义
勾选这条条件参不参与判定（改一下立刻重算）
连接首要 / 或 / 且
条件条件名（互差、观测时长、最终取值、分段间隔…）
参数该条件的参数，双击行即可改
命中满足这条条件的观测数（不是被它剔除的数量）

出厂的默认组合是：

(互差 连续3次 ≤5 μGal 或 互差 连续2次 ≤1 μGal) 且 观测时长 ≥35 s 且 最终取值=最新 且 分段间隔 >5 min

互差 / 最终取值 / 分段间隔

  • 互差：同一个测点（线号+点号）按时间排好后滑动窗口看连续 n 次，极差 ≤ 限差就算满足； 合格的那几个读数都标「满足条件」。
  • 最终取值：在每一轮观测里只留一条 —— 默认最新，也可以选最小距平 （离这一轮合格读数的均值最近的那条）。
  • 分段间隔：同一点相邻两次观测间隔超过这个时间（默认 5 min）就算新的一轮。 上午、下午各测一轮就各留一条。这一条自己不剔除任何观测。
结果表里的「处理理由」列会写清楚每行为什么留/不留： 最终取值（本轮被挑中的那条）、满足条件（通过了条件但本轮挑了别的）、 带条件名的描述（被它剔除）。

参数组合（筛选条件下拉）

下拉框里是出厂内置组合 + 你自己存的组合。切换组合 = 整条条件栈被替换并全部勾选、立即生效。 改完想留着，点「参数组合 ▾ → 存参数」，命名保存（Ctrl+S 也行）。

6. 结果表复核

按钮作用
只看人工改过的只看你手工动过的那些观测
👉 只看筛选结果在「显示全部数据」与「只显示筛选结果」之间切换
取消选中只放开表格的行选中（高亮取消），勾选状态一个都不动
勾选选中把表格里选中的行勾上（= 人工保留）
取消勾选把表格里选中的行取消勾选（= 人工剔除）
⛶ 表格+图形 最大化把结果表和图形一起放进一个独立窗口并最大化（左表右图，可拖动分界；关掉就放回）
恢复条件结果撤销全部人工干预，回到条件筛选的结果
导出 / 复制 / 列设置见第 9 节

  • 「选中」和「勾选」是两回事：选中=表格里那一行被高亮（用于图形联动、复制、成批操作）； 勾选=这条观测保留/剔除（进导出）。
  • 行底纹：打勾（保留）的行是淡黄（两个黄交替，用来区分相邻测点）；其余按测点交替白 / 浅蓝。
  • 点表头可排序（数值列按数值排），拖动表头可换列序（导出/复制跟着走）。
  • Ctrl+C 或右键「复制选中的观测…」= 把当前结果按制表符复制，可直接粘进 Excel； 有选中行就只复制选中的行。
  • 「只看人工改过的」这一屏正好用来复核：勾选框和理由列都在。

7. 图形

四种视图：读数 vs 时间 / 互差带（按测点居中）/ 倾斜·温度 vs 时间 / 仪器潮汐 vs 理论潮汐。

操作效果
单击散点在表里选中该观测（不改变保留状态）
Ctrl + 单击该观测取反（保留↔剔除）
拖动 / 滚轮平移 / 以光标为中心缩放
Shift + 拖动框选一批 → 表格里选中
Ctrl + 拖动框选一批并整体取反
R / 工具条 ⌂图形复位回全览

符号：保留的点是实心圆（选中时更大更亮），被条件剔除的是灰色 ×，范围外的更淡。 切到「只看筛选结果」时，被剔除的点直接不画（不会还能悬停/点中）。

8. 查看原数据（F3）

用独立窗口预览手簿原文（带源行号，一个字符都不改），用来核对解析对不对、看手簿头信息。

  • 跟随表格选中（默认勾）：表格里点哪一行，预览就滚到对应源行并高亮。
  • 表格里 Ctrl / Shift 多选后，窗口下方 ◀ 上一条 / 下一条 ▶ 可在这几条之间逐条走 （只选中一条时它们是灰的 —— 没得跳）。
  • 查找：输入关键词回车即查，下一个 / 上一个；勾「只看命中行」只显示含关键词的行， 查找框里按 Esc 清空。

9. 导出 xlsx

  1. 点「导出 xlsx…」→ 选格式与内容 → 选保存位置。
  2. 选项：导出格式（原始数据格式 / 自定义列序）、导出内容（仅保留的观测 / 范围内的全部观测）、 附「处理理由」列、附 Survey 文件头（默认勾上）。
  3. 文件名会自动带上日期与 Survey，例如 914_20250701_2025-07-01_nx914_挑选_原始格式.xlsx。
内容导出成什么
读数 / 标准差 / 时长 / 倾斜 / 温度 / 潮汐 / REJ / 高程 / 十进制时间数值（Excel 里能直接算、能排序）
线号 / 点号去零后是纯数字就写数值，并保留原文的小数位数（15.0000000 → 15）
时刻 / 日期真时间 / 真日期：显示还是 07:42:01 / 2025/07/02， 但 Excel/WPS 认它们，不再提示「未识别为日期」
Survey 文件头（勾选时）写在表格最上面：Survey name / 仪器 S/N / 操作者 / 经纬度…， 其中 S/N、ZONE、GMT DIFF. 是数值，Date/Time 是真日期时间，经纬度保持原文（106.6000000 E）
导出的是"原始数据格式"：列序、写法与手簿原样，去掉了每行开头的空格 —— 可以直接归档或替换手簿。

10. 参数会被记住

界面上的习惯都会记住，下次打开还是上次的样子：

  • 窗口大小与位置、三栏宽度；
  • 「显示全部数据 / 只看筛选结果」、「只看人工改过的」、图形视图；
  • 列序与显示的列；
  • 导出对话框的四个选项（含是否附 Survey 文件头）；上次导出的文件夹；
  • 整条条件栈（连参数与勾选状态）。想回出厂默认：在「筛选条件」下拉里选第一个内置组合。

它们就放在软件的安装目录下（跟着程序走，拷到别的机器/U 盘也一起带着）：

文件内容
config\settings.json界面习惯（窗口、视图、列序、导出选项…）
config\presets.json你保存的条件参数组合

想看这两个文件到底在哪、想直接打开那个文件夹：关于 → 配置文件位置。

如果软件装在 C:\Program Files 这类不让写的目录里， 这两个文件会自动放到「当前用户的应用数据目录」下（%LOCALAPPDATA%\CG5Picker）， 界面上会写明实际位置 —— 不影响使用。

12. 常见问题

现象原因与办法
一条数据都没有日期与 Survey 两条线都要勾（缺一边=0 条）；也可能是条件太严 —— 看日志里「各条件命中」与「剔除构成」。
某条条件「命中 0」命中 = 满足该条件的条数。时长命中 0 说明这批数据时长都不够 （常见是仪器里观测时长设成了别的值）。
把「时长」的连接改成「或」后几乎全放行「或」组只要一条满足就算过，而时长是最松的一条。 门槛类条件请用「首要」或「且」（见第 5 节）。
一个测点只剩一条，可是上午也在测「分段间隔」把一天切成了几轮，每轮各留一条。 如果只想留最后一条，把「分段间隔」调得比整天还大（比如 1000 min）。
导出的日期/时刻在 WPS 里被打绿三角旧版本才会。现在时刻/日期写真时间/真日期， 显示不变但 Excel 认它；若还提示，把那一列的格式设为 yyyy/mm/dd。
点号列出现一大串 0手簿里点号写成 15.0000000；导出时按数值写并保留原长度， 显示就是 15.0000000。要整数请在 Excel 里设格式 0。
图形窗口看不过来点「⛶ 表格+图形 最大化」：表格和图形一起进独立窗口并最大化。
